# Advanced EDA & Feature Engineering

This project focuses on cleaning and preparing raw data for Machine Learning using Python. It includes Exploratory Data Analysis (EDA), handling missing values, removing duplicate records, detecting and treating outliers using the IQR method, feature engineering, and data visualization. The cleaned dataset is exported for further Machine Learning tasks.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* OpenPyXL

## Project Features

* Data loading from Excel
* Data exploration and statistical analysis
* Missing value handling
* Duplicate removal
* Outlier detection and treatment
* Feature engineering
* Data visualization
* Exporting the cleaned dataset

This project was completed as part of the DecodeLabs Data Science Industrial Training Program to strengthen practical skills in data preprocessing and feature engineering.
