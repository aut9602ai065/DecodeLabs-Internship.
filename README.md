project 3

This project uses K-Means Clustering and Principal Component Analysis (PCA) to segment customers based on their purchasing behavior. The dataset is preprocessed by handling missing values, encoding categorical features, and scaling numerical data. The optimal number of clusters is determined using the Elbow Method and Silhouette Score. Finally, the clusters are analyzed to create meaningful customer personas, helping businesses improve marketing strategies, customer engagement, and decision-making

project 4
**E-commerce Data Analytics with NLP & Sentiment Analysis** is a Python-based project that analyzes an e-commerce orders dataset to generate valuable business insights. The project includes data cleaning, preprocessing, feature engineering, exploratory data analysis (EDA), and data visualization. Since the original dataset did not contain customer reviews, a synthetic review dataset was created for educational purposes to perform NLP and Sentiment Analysis using TF-IDF, Naive Bayes, and SVM. The project also provides insights into sales trends, customer behavior, product performance, and order status through interactive visualizations and dashboards.

Technologies Used
Programming Language: Python
Development Environment: Jupyter Notebook / VS Code
Data Processing: Pandas, NumPy
Data Visualization: Matplotlib, Seaborn
Natural Language Processing (NLP): NLTK
Text Vectorization: TF-IDF (Scikit-learn)
Machine Learning: Naive Bayes, Support Vector Machine (SVM)
Data Splitting & Evaluation: Scikit-learn
Dataset: Microsoft Excel (.xlsx)
Dashboard (Optional): Power BI / Streamlit
